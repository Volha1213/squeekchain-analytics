## Project name

Squeekchain Analytics

## Short description

An independent Squeekchain analytics dashboard that turns real wheel telemetry, settled block activity and SQK supply data into transparent, interactive views.

## Integration description

Squeekchain Analytics helps the community follow WHEELY9000 activity, settled Squeek blocks and SQK economics. It uses the official public API for live wheel speed, accepted work, observation coverage, settlement batches, difficulty, supply and staking totals. Users can compare periods, inspect chart values, export data and check each source's status. The app validates official response schemas, preserves exact token amounts and keeps unavailable readings unknown. It distinguishes optimistic projections from settled work, labels settlement rate accurately and discloses the difference between current API addresses and the dated documentation record. Built with Next.js, TypeScript and Tailwind CSS, it supports mobile screens, dark/light themes and automatic refresh. It is a read-only analytics tool: it does not sign transactions, invent metrics or claim independent RPC verification.
